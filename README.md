🍽️ Food Admin Dashboard

Food Admin Dashboard is a React-based admin application for managing a food delivery business. It provides a dashboard to monitor orders, food items, customers, inventory, sales, and other administrative activities.

✨ Features

* Admin login
* Dashboard overview
* View sales and order statistics
* Manage orders
* Manage food/menu items
* Manage food categories
* Manage customers
* Monitor inventory and stock
* View analytics and reports
* Manage application settings
* Update admin profile information
* Theme switching
* Loading and error handling

🛠️ Tech Stack

* React
* JavaScript (ES6+)
* HTML5
* CSS3
* Redux Toolkit
* React Router
* Axios
* React Icons
* Vite
* JSON Server

📂 Project Structure

* Components – Reusable UI components
* Pages – Different sections of the admin dashboard
* store.js – Redux store configuration
* Slices – Redux Toolkit slices for managing application state
* db.json – Contains mock API data

🚀 Getting Started

Prerequisites

* Node.js
* npm

Installation

Clone the repository:

git clone https://github.com/Aishwaryasri3/food-admin-dashboard.git

Navigate to the project folder:

cd food-admin-dashboard

Install the dependencies:

npm install

Start JSON Server:

npx json-server db.json --port 3000

Open another terminal and start the React application:

npm run dev

Open the local URL provided by Vite in your browser.
